# مواصفات التصميم — مطابقة واجهة طفرة

مستخرجة من `LMS-Home-ReactJS` (موقع الطالب) و `LMS-Admin-ReactJS` (لوحة الأكاديمية).
الهدف: المدرس والطالب يحسوا إنهم على طفرة — عشان الانتقال لطفرة بعدين يبقى طبيعي.

## موقع الطالب

**الخط:** طفرة بتستخدم OMNES Arabic (تجاري — ممنوع نوزّعه). البديل: **Almarai** من Google Fonts
(`https://fonts.googleapis.com/css2?family=Almarai:wght@300;400;700;800&display=swap`) — موجود كـ fallback في طفرة نفسها.
المدرس يقدر يختار خط تاني (Cairo / IBM Plex Sans Arabic / Tajawal) — `--font-primary`.

**ألوان العلامة (متغيرة لكل أكاديمية — CSS variables من الإعدادات):**
| التوكن | الافتراضي |
|---|---|
| `--color-primary` | `#3B82F6` (المدرس بيغيّره) |
| `--color-secondary` | `#6B7280` |
| `--color-accent` | `#EF4444` |
| success / warning / danger | `#10B981` / `#F59E0B` / `#EF4444` |

**المحايدات (ثابتة):**
| | فاتح | غامق |
|---|---|---|
| خلفية الصفحة / السطح | `#FFFFFF` | `#0D0D0D` |
| سطح بديل | `#F1F1F1` | `#161616` |
| لوحة الطالب: خلفية | `gray-50` وكروت بيضا | سطح `#101215`، حد `#23262B` |
| النص الأساسي | `#1E1E1E` | `#F0F0F0` |
| نص باهت | `#A6AEB9` | |
| الحدود | `#E4E4E4` | `#282828` |
| تينت الأساسي | `#E2EEFF` | `#002045` |
| عناوين كحلي | `#002045` / `#112D55` | |
| ذهبي (مكافآت بس) | `#EFA425` | `#F1AF3D` |

الشارات: `color-mix(in srgb, var(--color-primary) 14%, transparent)`؛ عنصر القايمة النشط ١٢٪.

**المقاسات:** Display 900 `clamp(2rem,5vw,3.5rem)` · Headline 700 `clamp(1.5rem,3vw,2.25rem)` · Title 600 1.25rem · Body 400 1rem/1.6 · Label 500 .875rem. عنوان الهيرو `32px → 42px` bold.
**الانحناءات:** ٨px (أزرار/حقول/كروت)، ١٢px عناصر السايدبار، ١٦px البانر والكروت الكبيرة، ٢٤px السايدبار العائم، full للأفاتار.
**الظلال:** مسطّح في الراحة. hover الكارت: `translateY(-10px)` + `0 20px 40px rgba(0,0,0,.2)`. زرار أساسي hover: `shadow-[0_0_25px] shadow-primary/50 scale-105`.
**نقاط الكسر:** `lg = 1025px`. الحاوية في النص، أقصى عرض ~`1280–1536`.
**الأيقونات:** Phosphor (duotone للقايمة) + Lucide. (في Blade: SVG inline أو Heroicons الموجودة.)
**الحركة:** fadeIn .8s، slideUp .8s، hover ٢٠٠–٥٠٠ms، لمعة ١٠٠٠ms.

### الشاشات
- **الناف بار:** ثابت أبيض بظل. لوجو، «الصفوف» (منسدلة)، الكورسات، بحث، تبديل الوضع الليلي. زائر: «دخول» + «اشترك». طالب: أفاتار بقايمة (حسابي، كورساتي، امتحاناتي، المحفظة، خروج). موبايل: هامبرجر يفتح درج.
- **الرئيسية:** هيرو ← الصفوف ← عن المدرس ← كورسات مقترحة ← كل الكورسات ← آراء ← فوتر.
- **الهيرو:** عمودين (صورة المدرس + نص). «اكتشف طريقك مع» + **اسم المنصة** بخط كبير مع خط متحرك تحته، وصف `#5A6574` 20px، زرار (زائر: «انضم الآن» / طالب: «كورساتي»)، ٣ شارات مميزات. الصورة 4:3 بحد ٦٠٠px. خلفية فاتحة بنقشة.
- **كارت الكورس (360×455):** شريط ملوّن فوق بكود الصف؛ صورة 16:9 بلمعة؛ شارة الصف؛ اسم المدرس بأفاتار؛ العنوان سطرين بخط تحته بيكبر مع hover؛ وصف ٧٠ حرف؛ فوتر بحد علوي: السعر في كبسولة متدرجة (primary → secondary) والقيمة في شيب أبيض، أو «مجاني» أخضر.
- **صفحة الكورس:** هيدر (عنوان 40px `#002045`، وصف قصير، فيديو تعريفي). ديسكتوب: محتوى ٢/٣ + **كارت شراء لاصق** ١/٣ (`sticky top-24`): صورة، السعر (والقديم مشطوب لو فيه خصم)، **خانة كوبون/كود شحن + «تطبيق»**، أزرار الدفع (المحفظة / تحويل بإيصال / كود)، أو «ادخل الكورس» للمشترك، قايمة (عدد الدروس، الامتحانات، مدة المشاهدة). تابات: **المحتوى | الوصف**. المحتوى أكورديون: كل جزء صف بحد مدوّر، أيقونة 32px على `primary/10`، العنوان، «N فيديو • N امتحان»، سهم بيلف. جوه: الدروس بأيقونة النوع وقفل على المدفوع.
- **مشغّل الدرس (برا اللوحة، شاشة كاملة):** شريط علوي (لوجو + اسم الكورس + شريط تقدّم `h-1.5` + «محاضراتي» + الوضع الليلي). ديسكتوب: **سايدبار ٥٠٠px** (كروت الأجزاء radius 16 حد `#eee` أيقونة متدرجة `#2b42a0 → #5f7eff`، صفوف الدروس radius 8 + علامة خلص + شارة مجاني + قفل) + المحتوى (يوتيوب/PDF/نص) + السابق/التالي تحت (`rounded-xl` outline + solid). موبايل: السايدبار درج.
- **الامتحان:** بداية (معلومات + ابدأ) → أسئلة → ملخّص. هيدر: العنوان، شريط اللي اتجاوب، **العداد 24px bold** (بيصفّر/يحمرّ). أرقام الأسئلة دواير 32px (اتجاوب/مرجعية). الاختيار: `p-4 rounded-lg border-2` — عادي `border-gray-200`، مختار `bg-primary text-white`، صح `bg-green-500`، غلط `bg-red-500`. التفسير `bg-gray-50 rounded-lg`. مودال «الوقت خلص» بدايرة ساعة حمرا.
- **النتيجة:** لوحة بخلفية `primary 5%`: كروت أرقام بيضا `rounded-2xl` بالرقم `text-5xl` (صح/غلط/من غير إجابة) + الدرجة والنسبة + «مستني تصحيح المقالي» لو فيه.
- **المحفظة / كود الشحن:** مودال/كارت: دايرة 64px `primary/10` بأيقونة تذكرة، حقل الكود (`py-3 ps-12 rounded-lg`)، «اشحن» + «إلغاء». نجاح: علامة خضرا. غلط: دايرة حمرا + «جرّب تاني». جدول الحركات: إيداع `bg-green-50 text-green-700`، سحب `bg-red-50 text-red-700`.
- **الحساب:** كارت `rounded-2xl` بحد: أفاتار، الاسم + حالة، أزرار «تعديل البيانات» و«تغيير كلمة السر»، (الكود، الموبايل، الصف)، ٣ مربعات أرقام متقطعة.
- **لوحة الطالب:** سايدبار عائم `lg:w-72 inset-y-4 rounded-3xl` (لوجو، الطالب، القايمة، خروج أحمر). عنصر القايمة `px-3 py-2.5 rounded-xl`، النشط: نص primary + خلفية ١٢٪ + شريط ٤px. موبايل: **شريط سفلي** ٤ أعمدة (الرئيسية، كورساتي، المحفظة، حسابي). بانر ترحيب `rounded-2xl` بلون primary.
- **الدخول/التسجيل:** خلفية كاملة؛ ديسكتوب: كارت كبير بنصّين (صفحة الأكاديمية: صورة + لوجو + اسم + سوشيال | الفورم). الدخول: الموبايل + كلمة السر. التسجيل: الاسم، الموبايل، موبايل ولي الأمر، كلمة السر وتأكيدها، الصف، المحافظة، عام/أزهر.
- **الفوتر:** خلفية بموجة؛ لوجو + «تابعنا» بدواير 40px؛ فاصل؛ «© السنة» + **«مطوّر بواسطة طفرة»** بلوجو طفرة ولينك.
- **التنبيهات:** فوق، ٥ ثواني، ملوّنة، ٣ بالكتير.

- الأساسي `#419DF1`، success `#17C653`، warning `#F6C000`، danger `#F8285A`، info `#7239EA`.
- الرمادي: `#F9F9F9 #F1F1F4 #DBDFE9 #C4CADA #99A1B7 #78829D #4B5675 #252F4A #071437`.

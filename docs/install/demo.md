# نسخة التجربة (Demo)

نسخة عرض فيها أكاديمية «شكلها شغّالة»، وصفحات الدخول فيها زراير **«ادخل كـ…»** بضغطة. مناسبة لعرض المنصة على مدرسين، أو لتجربتها قبل ما تثبّتها بجد.

> ⚠️ **ماتشغّلهاش على أكاديميتك الحقيقية.** `lms:demo --fresh` بيمسح القاعدة كلها.
> الأمر بيرفض يلمس منصة متثبّتة بـ `/install` أو `lms:install`.

## التشغيل

```bash
# .env
DEMO_MODE=true

php artisan lms:demo            # أول مرة: تثبيت + بيانات
php artisan lms:demo --fresh    # امسح كل حاجة وابدأ من الأول
```

**Docker / Coolify:** حط `DEMO_MODE=true` في متغيّرات البيئة. الحاوية بتشغّل `lms:demo` بدل `lms:install` أول مرة. `LMS_ADMIN_EMAIL` مش مطلوب.

## الحسابات

| الحساب | الدخول | يقدر يعمل إيه |
|---|---|---|
| المدرس | `teacher@demo.test` | كل حاجة |
| المساعد | `assistant@demo.test` | الإيصالات والتصحيح والطلبة |
| مشاهد | `viewer@demo.test` | يشوف بس |
| الطالب | `01000000000` (على `/login`) | مشترك في كورسين، ومعاه ٣٠٠ جنيه في المحفظة |

كلمة السر لكل الحسابات: `DEMO_PASSWORD`، والافتراضي `demo-password`. الزراير بتدخّلك من غير كلمة سر أصلاً.

## البيانات

- **المحتوى:** ٣ صفوف دراسية، و٤ كورسات كيمياء بأجزاء ودروس (يوتيوب ونص) وامتحانات (اختيار من متعدد ومقالي).
- **الطلبة:** ٢٠ طالب على مدار الشهرين اللي فاتوا، منهم مشتركين بالإيصال ومن السنتر وفي الكورس المجاني.
- **الإيصالات:**
  - ٧ مقبولة و١ مرفوضة.
  - **٤ مستنية المراجعة**، منها واحد بنفس صورة اللي قبله عشان يبان تحذير «إيصال مكرر».
- **الامتحانات:** محاولات بدرجات متنوّعة، ونص الإجابات المقالية **مستنية التصحيح**.
- **باقي البيانات:** ٣ إعلانات (منها واحد متثبّت)، ٤٥ كارت شحن وكود تجربة `111122223333`، كوبون `WELCOME20`، وطريقتين دفع.

## نسخة مفتوحة للناس

```bash
DEMO_AUTO_RESET=true     # ترجع لأصلها كل يوم
DEMO_RESET_AT=04:00
```

- **محتاج سطر الـ Cron** (`schedule:run`) زي أي تثبيت.
- **في الموقع واللوحة شريط «نسخة تجربة»** بيقول ميعاد الرجوع.
- **حد الأجهزة مقفول في نسخة التجربة،** عشان كل الزوار بيدخلوا نفس حساب الطالب.

## الأمان

الدخول بضغطة بيشتغل بس لو الشرطين صح مع بعض:

1. `DEMO_MODE=true`.
2. المنصة متثبّتة بـ `lms:demo`: فيه علامة `"demo": true` في `storage/app/installed.json`.

لو متغيّر البيئة اتفعّل بالغلط على أكاديمية حقيقية، مفيش زراير ولا مسار دخول بيشتغل (404). ولا حساب غير اللي في `config/demo.php` بيتدخل.
